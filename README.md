# 🎨 Real-Time Collaborative Drawing Canvas

A multi-user collaborative drawing app built with **HTML5 Canvas**, **Express.js**, and **Socket.io**.

## 🚀 Features
- Real-time drawing across multiple users
- Brush, eraser, color, and stroke width tools
- Global undo/redo
- User list and session tracking
- Clear canvas for all

## 🧰 Tech Stack
- Frontend: HTML5, CSS, JavaScript
- Backend: Node.js, Express.js, Socket.io
